# Search visibility for ethicraft.in

## What is already built in

All of the on-page and technical work — the part that is fully under your
control — ships with the site:

| Item | Where |
| --- | --- |
| Title and meta description targeting *EthiCraft PICT* and *Pune* | `views/index.html` |
| Canonical URL (`https://ethicraft.in/`) | `views/index.html` |
| Open Graph + Twitter cards for link previews | `views/index.html` |
| Geo meta (Maharashtra, PICT's coordinates) | `views/index.html` |
| JSON-LD: `EducationalOrganization`, `CollegeOrUniversity`, `WebSite`, `WebPage`, `BreadcrumbList`, `FAQPage` | `views/index.html` |
| `robots.txt` pointing at the sitemap | generated by `server/seo.js` |
| `sitemap.xml` with `lastmod` from real event data | generated by `server/seo.js` |
| `lang="en-IN"`, one `<h1>`, ordered headings | `views/index.html` |
| Admin portal marked `noindex` and unlinked from the public site | `views/login.html`, `views/admin.html` |
| Compression, caching, fast first paint | `server/index.js` |

The FAQ block is the highest-leverage piece: it targets the questions people
actually type — *"what is EthiCraft club PICT"*, *"how to join EthiCraft"* — and
is eligible for rich results in Google.

## What no amount of code can do

Ranking is Google's decision, not a setting. A brand-new domain with no
inbound links does not appear at the top for competitive terms regardless of
markup quality. Realistically:

- **"EthiCraft PICT" / "EthiCraft club"** — you should rank first within a few
  weeks. It is your own brand name and nothing else competes for it.
- **"PICT clubs", "student clubs in Pune"** — months, and only with real
  inbound links. PICT's own site and established directories will outrank a new
  domain until you earn authority.

Anyone promising a #1 ranking for competitive terms on a schedule is guessing.

## Do these five things after deploying

1. **Google Search Console** — <https://search.google.com/search-console>.
   Add `ethicraft.in`, verify via a GoDaddy DNS `TXT` record, then submit
   `https://ethicraft.in/sitemap.xml`. Nothing else here matters as much.
2. **Bing Webmaster Tools** — <https://www.bing.com/webmasters>. Imports
   straight from Search Console, and its index feeds several other search
   tools including DuckDuckGo.
3. **Get linked from a `.edu` domain.** Ask the PICT web team to link
   `ethicraft.in` from the official clubs page. One link from `pict.edu` is
   worth more than a hundred directory submissions.
4. **Link from every profile you already control** — the club's Instagram and
   LinkedIn bio, event posters, WhatsApp group descriptions, the PPT footer.
5. **Publish events regularly.** The sitemap's `lastmod` updates automatically
   whenever you publish through the admin portal, which is a genuine freshness
   signal.

## Verify it is working

```bash
curl https://ethicraft.in/robots.txt
curl https://ethicraft.in/sitemap.xml
```

Then run these once the site is live:

- **Rich Results Test** — <https://search.google.com/test/rich-results>
- **PageSpeed Insights** — <https://pagespeed.web.dev/>
- **Social preview** — <https://www.opengraph.xyz/>

## Keeping it accurate

The address and coordinates in the JSON-LD block are PICT's Dhankawadi campus.
If the club's contact details change, update them in **both** places in
`views/index.html`: the visible footer text and the `EducationalOrganization`
block. Search engines cross-check the two.
